# Revisión de calidad para lanzamientos web y API

Soy Sergio Moyano, QA Automation Engineer con más de cuatro años de experiencia en pruebas funcionales, automatización web, APIs y backend. He trabajado en productos financieros y flujos transaccionales. Ayudo a equipos pequeños a detectar problemas en los recorridos que más importan antes de publicar una versión.

## Revisión piloto de alcance fijo

**Para quién:** equipos que están por lanzar o actualizar una web o aplicación con API y necesitan una revisión externa concreta.

**Qué incluye:** hasta tres flujos críticos acordados, hasta dos endpoints de API relacionados, un entorno de pruebas y una combinación de navegador de escritorio y tamaño móvil. Documento el alcance, ejecuto las comprobaciones, registro cada incidencia reproducible con pasos y evidencia, y entrego un informe priorizado. Incluye una revisión breve de las correcciones entregadas durante los siete días posteriores.

**Plazo orientativo:** tres a cinco días hábiles desde que recibo acceso al entorno, cuentas de prueba y criterios de aceptación.

**Precio piloto orientativo:** USD 250 por el alcance anterior. Si el producto necesita más flujos, navegadores, dispositivos, automatización mantenible o trabajo con datos sensibles, preparo una cotización específica antes de empezar.

**Límites:** el servicio no promete encontrar una cantidad determinada de errores. No incluye pruebas de penetración, certificación de seguridad, carga, accesibilidad integral ni transacciones reales. La automatización permanente se cotiza por separado.

La comunicación puede ser asincrónica en español o en inglés escrito.
