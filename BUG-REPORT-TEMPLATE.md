# Bug report template

- **Title:** `[Area] Concise description of the observed issue`
- **Environment:** URL, browser/version, OS, build/version, date/time and test account type (never include credentials)
- **Preconditions:** Relevant account state or setup
- **Steps to reproduce:** Numbered, minimal steps
- **Expected result:** What should happen
- **Actual result:** What happened instead
- **Evidence:** Screenshot/video/trace or sanitized request/response
- **Frequency:** Always / intermittent (include observed count)
- **Severity:** Critical / High / Medium / Low, with user/business impact
- **Reproducibility:** Reproducible / not reproducible / needs more data
