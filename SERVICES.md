# Focused web and API quality review

I am Sergio Moyano, a QA Automation Engineer with more than four years of experience in functional testing, web automation, APIs, and backend systems. My work has included financial products and transactional workflows. I help small teams check their most important user journeys before a release.

## Fixed-scope pilot

**Best for:** a team about to release or update a web product with an API that wants a focused external review.

**Scope:** up to three agreed critical user flows, up to two related API endpoints, one test environment, and one desktop browser plus a mobile viewport. I document the scope, execute the checks, report reproducible issues with steps and evidence, and deliver a prioritized summary. A short recheck of fixes submitted within seven days is included.

**Typical turnaround:** three to five business days after test access, accounts, and expected behavior are provided.

**Indicative pilot price:** USD 250 for the scope above. Additional flows, browsers, devices, maintainable automation, or sensitive data handling require a separate quote before work begins.

**Boundaries:** the review does not guarantee a specific number of findings. Penetration testing, security certification, load testing, a full accessibility audit, and real financial transactions are outside this pilot. Ongoing automation is quoted separately.

I work asynchronously in Spanish or written English.
